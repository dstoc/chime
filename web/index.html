Chime

Set up and manage administrator passkeys for this Chime server.

Connecting to Chime…

Set up the administrator

Enter the one time code printed by the Chime service, then register a passkey with user verification.

The code expired or was already used. An operator must stop Chime and run chime-server reset-admin --data-dir PATH to create another.

Administrator passkeys

Each action asks for a fresh passkey verification. Chime does not keep an administrator session.
